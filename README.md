# Research Retold Opportunities Dashboard

An interactive dashboard for reviewing and prioritising UKRI-funded projects with potential research communication needs.

The dashboard provides project search, filtering, evidence review, scoring, and a browser-local shortlist workflow.

## Data snapshot

- 2,259 active UKRI project records
- AHRC, ESRC, and Innovate UK coverage
- Snapshot date: 21 July 2026

## Notes

Shortlists, review decisions, and notes are stored in the visitor's browser and are not shared between devices.
